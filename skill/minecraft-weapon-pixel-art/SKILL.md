# Minecraft 武器像素画：固定 32×32 画板

这是一套工具和默认经验，不是规则书。下面的比例、材质、构图都是起点；你可以按武器设定和整体审美调整。`board.py` 检查技术项（尺寸、alpha、连通性、色数等），不评判美丑。

武器识别通常靠剪影和负空间，不靠堆花纹；但这条也是经验，不是法条。

## 为什么常用 32×32

- 32×32 通常能放下 1px 描边、1px 刃口、1px 高光、护手、金箍、斧须、后刺。
- 16×16 更适合 vanilla 小图标；战斧、军刀、大剑在 32×32 上通常更舒展。
- 固定画板让不同武器风格一致，也让“细节密度”可比较。
- 画板固定后，问题通常变成“这个像素该不该存在”，而不是“换不换尺寸”。

## 画板与工具默认值

- 画布：32×32 RGBA PNG；`board.py` 按这个尺寸渲染和检查。
- alpha：0/255；半透明可以用颜色和明暗模拟。
- 边距：工具默认把可见像素放在 `x=1..30, y=1..30`；右下 2×2 留给物品栏堆叠数字。
- 连通性：工具默认要求单连通；漂浮像素会报 error。
- 颜色：每种材质 3–5 个明暗是常见范围；整张图 9–15 色是常见密度，上限 32。
- 风格：无抗锯齿、无渐变、无文字、无背景、无发光、无粒子是默认；如果需要，也可以自己判断。
- 光：上左是常见默认；刃口亮边可以当“磨锋”的材质提示，而不是第二光源。

这些是工具的默认值，不是审美标准。

## 一种有效的工作顺序：先剪影，后材质

1. 可以先用占位色 `X` 画 alpha 剪影，先看形状，先不分配材质。
2. 渲染后看 `silhouette.png`：在 1x 大小下是否认得出是什么武器？
3. 认不出时，改形状通常比改颜色有效；当然也可以故意做抽象/装饰性剪影。
4. 剪影满意后，把 `X` 换成材质字符；外轮廓尽量连续。
5. 负空间通常有帮助：斧须和柄之间、护手和刃之间、刀背和握柄之间的缝隙，会让轮廓更透气。负空间是识别的一部分，但不是硬性要求。

## 武器原型与常见锚点

| 武器 | 常见锚点 | 常见负空间 | 常见观感问题 |
|---|---|---|---|
| 长剑 longsword | 直刃、护手、握柄、剑首 | 护手把刃和柄分开 | 刃太宽容易像砍刀；护手 floating |
| 军刀 saber | 弯刃、单锋、护手/护指、握柄 | 弯刃内侧的月牙形空隙 | 刃太直容易像长剑；弯度藏在颜色里 |
| 战斧 war axe | 斧头、斧须、后刺、金箍、斜柄 | 斧须和柄之间 | 实心三角容易像叶子；后刺像天线 |
| 镐 pickaxe | 横头、双尖、斜柄 | 头与柄的连接处 | 容易画成锤子；头太窄 |
| 弓 bow | 上下弓臂、握把、弓弦 | 弓臂和弦之间 | 弦断；弓臂对称得像括号 |

这些是常见识别线索，按设计取舍。

### 长剑 recipe（可调整）

- 轴线：左下握柄 → 右上剑尖，约 45°；其他角度也可以。
- 刃：刃根横向 6–7 格（垂直刃轴约 4–5px），向剑尖以 1px 台阶收窄到 1–2px；想更秀气可以更窄。
- 刃面：外圈深色描边，内部一条 1px fuller（血槽），一侧亮、一侧暗，是一个常见组合。
- 护手：与刃轴垂直，10–12px 长、2px 厚，金色；两端断开时容易读成两截。
- 握柄：7–9px 长、3–4px 宽，皮革/深色；连续 1px 缠绕带通常更像布/皮，棋盘格也可以但容易变噪。
- 剑首：4×4 金色，压住左下角视觉重心。
- 参考锚点（可调整）：护手中心约 `(11,21)`，剑尖约 `(27,3)`，剑首约 `(3,28)`。

### 巨剑 recipe（可调整）

- 从 `--template longsword` 开始是一个省事的起点；也可以从零画。
- 刃根横向 9–12 格；护手 13–15px；握柄 8–10px；剑首 4×4。巨剑的识别通常靠“宽刃 + 大护手”，不是靠更长。
- 护手可以做成贝壳形/弧形；两端接在刃轴和柄上时更稳。
- 32×32 放不下时，缩短刃长或缩窄刃根都是选择；看你想要的比例。
- 刃面可以加 1px 波浪/海晶纹；连续纹路通常比随机点更可读。

### 剑柄与护手的视觉关系

- 横护手配斜柄时，柄容易在视觉上折一下；一种常见处理是让柄垂直向下、居中在刃根，或者把护手改成垂直于刃轴。
- 斜护手配共线柄也常见：刃轴、护手中心、柄轴、剑首沿同一条斜线。
- 柄尾中心落在柄轴附近通常更稳；偏一点也可以是有意的设计。
- 没有唯一正确解，按整体轮廓和武器气质选择。

### 水晶军刀 recipe（可调整）

- 轴线：左下握柄 → 右上刀尖；弯度通常放在 alpha 剪影里更明显。刀尖可以向上/向外勾，也可以做反曲。
- 刃：刃根横向 5–6 格，单锋；凸面是刃口，凹面是刀背。
- 刃口：沿凸面一条 1px 亮边（crystal light/highlight），刀背用 deep/shadow。
- 晶面：2–3 条 1px facet 线，每像素渐变也可以但容易糊；高光可以放在刀尖和刃口转折处。
- 护手：金色，8–10px；加 1px 护指弓时，两端接上更稳。空间不够时用 8–10px 护手也成立。
- 握柄：6–8px 长、3–4px 宽，略弯，深色皮革；剑首 4×4 金色。
- 参考锚点（可调整）：护手中心约 `(10,21)`，弯刃控制点约 `(12,20) → (19,13) → (25,8)`，刀尖约 `(29,3)`。

### 短刀 recipe（可调整）

- 可用 `--template knife`；刃比长剑短 8–12 行，刃根横向 4–5 格，向刀尖收窄到 1px。
- 护手 6–8px、2px 厚；握柄 4–6px、3px 宽；柄尾 3×3。
- 折叠刀：刃身分成 3–4 段，每段 2–3px 厚，段与段之间留 1px 亮缝；连在同一刀脊时更稳。
- 半透明蜂蜡/蜜蜡：用“浅琥珀核心 + 亮刃口 + 深琥珀外描边”模拟透光；partial alpha 在画板里不可用，但可以用颜色模拟。
- 刀柄六边形蜂巢纹：连续 1px 折线通常更像六边形；逐像素棋盘格也可以，但容易变噪。

### 长枪 recipe（可调整）

- 可用 `--template spear`；枪杆 2–3px 宽、24–28 格长，枪头 5–7 格宽、8–12 行高。
- 枪头明显宽于枪杆时更容易读成枪；想要细枪头也可以，但容易被读成棍。
- 两侧导轨用 1px 线，沿枪杆平行走；两端接在枪箍/枪尾上时更稳。
- 枪尾坠饰：1px 链子 + 3–4px 碎片；链子接到枪尾时更稳。
- 枪头/枪杆用不同材质时，外描边可以用各自的 deep 色，枪箍用 metal ramp。

### 战斧 recipe（可调整）

- 斧头在右上，斧须向下勾，后刺向左上，金箍在刃和柄的机械连接处，是一个常见构图。
- 斧须和柄之间留 1–2px 透明缝时，头不容易变成实心三角/叶子。
- 后刺基部 2px 宽通常比 1px 天线更稳；想做细刺也可以。
- 柄是 3px 斜带：上缘 light、中间 base、下缘 shadow；金 pommel 压住左下角是一个常见做法。
- 参考示例：`examples/emerald_war_axe.json`。可以用它校准细节密度，也可以走自己的方向。

## 材质系统

`board.py init` 会生成这套字符表：

| 字符 | 角色 |
|---|---|
| `D` | 主材质 deep / 外描边 |
| `S` | 主材质 shadow |
| `B` | 主材质 base |
| `L` | 主材质 light |
| `H` | 主材质 highlight |
| `G` | 金色 deep / 描边 |
| `g` | 金色 shadow |
| `y` | 金色 base |
| `Y` | 金色 light |
| `w` | 握柄 deep / 描边 |
| `u` | 握柄 shadow |
| `o` | 握柄 base |
| `k` | 握柄 light |
| `X` | 品红占位色；最终图里通常换成正式材质 |

可用主题：`steel`、`deepslate`、`emerald`、`echo`、`sculk`、`copper`、`redstone`、`honey`、`amber`、`crystal`、`ender`、`amethyst`、`magnetite`、`obsidian`、`tidal`、`prismarine`、`shell`、`seaweed`、`blaze`。
握柄可以选任意带 `deep/shadow/base/light` 的主题（`wood`、`leather`、`seaweed`、`sculk` 等）。

### 多材质

```bash
python scripts/board.py init --out spec.json --template longsword \
  --primary deepslate --secondary echo --grip sculk --name echo_blade
```

`--secondary` 会额外生成一套 `d/s/b/l/h`。常见分工：

- `D/S/B/L/H`：主材质（刃/头/杆）。
- `d/s/b/l/h`：副材质（镶嵌、脉络、线圈、纹样）。
- `G/g/y/Y`：金属/配件 ramp。未必是金；铜护手、避雷针、枪箍、贝甲都可以用它，按设计改 hex。
- `w/u/o/k`：握柄（木、皮革、海带、布条）。
- `X`：剪影占位色。

第三种点缀可以手动加键（如 `m/n/p/q`），每种 3–5 个明暗；总色数上限 32。

### 常用做法

- **Material-aware outline**：用每种材质自己的 deep 色做描边，通常比全图纯黑更有材质感。
- **上左光**：上缘/左缘 light，下缘/右缘 shadow，是常见默认；其他光向也可以。
- **刃口亮边**：沿切割边的 1px light/highlight，可以当“锋”的提示；扩展到整个右半身也会变成另一种风格。
- **金色与机械关节**：护手、金箍、剑首、斧座放金色时更像结构件；随机撒金点也可以，但容易变装饰噪声。
- **缠绕带**：沿柄轴连续的 1px 斜带通常更像布/皮；`wowow` 棋盘格也可以，但容易变噪。
- **颜色预算**：3px 宽的刃用 3 个主色 + 描边就够；不必把 5 个色全用上。

## 细节密度参考

- 1px 描边、1px 刃口、1px 高光是比较稳的密度；2px 黑框也可以，但会更卡通。
- 2×2 的 macroblock 容易像 16×16 放大；如果就是要那种风格，也可以用。
- 细节可以长在 1px 网格上：剑尖收窄、斧须勾、护手端部、facet 线。
- 留 1px 边距和右下角 2×2 是工具默认；填满画板也可以，但在 GUI 里可能显得挤。
- 没有功能的装饰（符文、宝石、光环、粒子）可以删，也可以保留；看设计意图。

## 工作流（可选的低步数路线）

1. 标准武器可以先用比例模板；也可以从零画：

```bash
python scripts/board.py init --out spec.json --template longsword \
  --primary deepslate --secondary echo --grip sculk --name echo_blade
```

模板是比例骨架（整把都是 `X`），通常要加入自己的轮廓、尖端、护手/刀镡变化；直接交付也可以，但会和其他模板武器比较像。
可用模板：`longsword`、`crystal_saber`、`war_axe`、`knife`、`spear`。巨剑可以用 `longsword` 加宽；没有合适模板时用 `--template none` 生成空白板。

2. 在 `spec.json` 的 `rows` 里把 `X` 换成材质字符。可以写一个小 Python 脚本批量填行，脚本留在输出目录方便复现。
3. 快速迭代：每轮可以输出 candidate、review 和校验摘要：

```bash
python scripts/board.py render --spec spec.json --out candidate.png --preview-dir . --fast
```

`review.png` 一张图包含 8x 中灰/浅色/深色、GUI 16px、silhouette 五个面板；通常读这一张就够，也可以逐张看 `preview_8x*.png`。

4. 先修剪影，再修材质。review 的 `silhouette` 和 `GUI 16px` 面板适合判断识别度；8x 面板适合看描边和材质。
5. 需要具体坐标时加 `--ascii`，它直接打印 32 行字符图，比读图更快。
6. 通常两轮左右：剪影轮 + 材质轮；如果第一版已经满意，可以提前停。
7. 最终交付可以去掉 `--fast`，出全套 preview，并生成 process.md 骨架：

```bash
python scripts/board.py render --spec spec.json --out candidate.png --preview-dir . --process-template
```

8. 画多把武器时：可以先把所有 spec 写好，再用一条 Bash 命令批量 render，然后一次性看各自的 `review.png`；也可以一把一把来。
9. `validation` 的 error 通常要修；warning 可以按设计判断。stdout 已经有摘要，是否再读 JSON 看需要。
10. 交付 `candidate.png`、`review.png`、`preview_8x*.png`、`silhouette.png`、`validation.json`、`spec.json`、`process.md`。

## 工具输出

- `review.png`：常用检查图。一张图里依次是 8x 中灰、8x 浅色、8x 深色、GUI 16px、silhouette。
- `--fast`：写入 `candidate.png`、`review.png`、`validation.json`，适合迭代。
- 不加 `--fast`：额外写 `preview_8x.png`、`preview_8x_light.png`、`preview_8x_dark.png`、`silhouette.png`，适合最终交付。
- `validation.json`：原始数据；stdout 已有摘要，通常不需要为了摘要再打开。
- `--ascii`：把 32 行字符图打印到 stdout，查坐标时比读图快。
- `--process-template`：如果 `process.md` 不存在，写一个带当前指标的骨架；设计说明由 agent 填。

## 工具会检查什么（技术项）

`board.py render` 自动写 `validation.json`：

- 尺寸 32×32。
- alpha 0/255。
- bbox 在 1..30。
- 右下 2×2 透明。
- 单连通；漂浮像素会报 error。
- 可见颜色 ≤32；>24 会给 warning。
- 可见像素 <60 会 error（太稀疏）；<110 会给 warning（很可能是 16×16 直接放大）；>550 会给 warning。
- `X` 占位色残留会给 warning。

这些是技术检查，不是审美评分。error 通常要修；warning 可以按设计判断。

## 常见观感问题与可选处理

| 症状 | 可能原因 | 可选处理 |
|---|---|---|
| 剑头像叶子 | 头是实心三角，负空间不足 | 收窄颈部、加斧须/凹口、留出柄与头之间的缝；也可以保留这种叶片感 |
| 后刺像天线 | 1px 细线，基部没接上 | 基部加到 2px 或直接接在斧座/头上；也可以做细刺 |
| 护手 floating | 护手和刃/柄之间有透明缝 | 让护手中心压住刃轴，或让端部与刃/柄共享 1px |
| 剑柄看起来歪/折 | 横护手配斜柄，或柄尾偏出柄轴 | 改垂直柄、改斜护手，或接受这个折角作为设计 |
| 柄像棋盘格 | 逐像素交替明暗 | 沿柄轴画连续 1px 带；棋盘格也可以作为缠绕纹理 |
| 描边有洞 | 外轮廓之外没检查内凹处 | 把暴露在透明背景上的像素换成该材质的 deep 色 |
| 军刀像长剑 | 弯度藏在颜色里 | 改 alpha 剪影：刀尖上勾，凸面刃口，凹面刀背 |
| 32×32 像 16×16 放大 | 2×2 macroblock | 用 1px 台阶重画轮廓，加 1px facet/bevel；也可以保留 macroblock 风格 |
| 画面太满 | 装饰太多 | 删掉非功能元素，或保留但接受更密的构图 |
